## 📌 1. 專案核心目標與背景
- **專案名稱**：士林電機 FA 業務戰情與報價系統 (PWA 企業整合版)
- **開發目標**：
  整合過去零散的 Streamlit 日報、PySide6 業務桌機工具與舊 PWA，重構為可在 **Windows 電腦、平板、手機跨裝置運行** 的統一現代化 Web 應用程式。
- **三大核心業務支柱**：
  1. **案件管理 (三層理論)**：第 1 層每日拜訪日報 (OGSM 行動) ➔ 第 2 層潛在商機 (CRM 機會) ➔ 第 3 層專案案件 (Deal 標案推進)。
  2. **報價單管理 (Append-Only 防呆)**：三段式單號 `Prefix-Seq-Rev`，修改另存新版次，嚴格禁止 UPDATE 覆寫舊報價。
  3. **專案售價管理**：低折讓破底門檻自動連鎖帶出案件競爭情資、經銷底價與毛利審核。

---

## 🛡️ 2. 系統架構六大不可違背鐵律 (開工前必讀)
1. **資料讀寫唯一窗口**：所有資料存取（SQLite、未來 Google 雲端或 SQL Server Express），**100% 必須透過 `data_access.py`**，畫面 (UI) 與 API 絕不直接拼接 SQL。
2. **報價單 Append-Only 鐵律**：報價單一經建立，歷史版次不可抹滅。改動必須產生新版號（如 `QT-2026-0001-02`），以利溯源查核。
3. **單一窗口免重複輸入**：業務於日報選取客戶時，系統自動帶入統一編號、電話、地址與預設聯絡人。
4. **介面純淨線條圖示 (Zero Emoji)**：參照 Windows 11 / Office Fluent 洗鍊單色 SVG 線條，**嚴禁使用彩色 Emoji 表情符號**（避免 Windows CP950 編碼當機與視覺廉價感）。
5. **字型與字級規範**：全站預設採用「微軟正黑體 (Microsoft JhengHei)」，預設字級「12pt」，以 CSS 變數封裝，支援後續設定頁動態切換。
6. **外觀顯示模式**：支援「裝置 (跟隨系統)」、「淺色」、「深色」切換，並自動記憶於本地瀏覽器。

## 💡 7. 常見問題與 Windows 環境避坑指南
1. **Windows 控制台中文亂碼問題**：
   - 寫 Python 讀寫檔案一律指定 `encoding="utf-8"`。
   - 主控台輸出禁止印彩色 Emoji，請使用 `[OK]`、`[TEST]` 等標籤。
2. **本機伺服器啟動方式**：
   ```cmd
   cd /d D:\Python\_PWA
   .\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8000
   ```
   瀏覽器開啟：`http://127.0.0.1:8000/`
